# Условия использования и политика данных

## 1. Введение

Данный сервис («Бот») разработан и управляется **FarGoneE**. Используя Бота, пользователь соглашается с условиями, изложенными в настоящем документе.

Бот предоставляет инструменты для хранения, организации, просмотра и, при необходимости, публикации контента через Telegram. Сервис может включать как бесплатные, так и премиум-функции.

Использование Бота означает согласие пользователя с настоящими Условиями использования и Политикой данных.

---

## 2. Модель хранения данных

Бот использует инфраструктуру Telegram для хранения и управления пользовательским контентом. Контент, загружаемый или управляемый через Бота, может храниться в одной из следующих моделей.

### 2.1 Стандартное хранение

В стандартном режиме хранения пользовательский контент размещается в инфраструктуре, управляемой Ботом.

- Пользовательский контент по умолчанию не является публичным.
    
- Третьи лица не имеют доступа к пользовательским данным через Бота.
    
- Администраторы сервиса могут получать доступ к контенту только при необходимости, например для:
    
    - модерации,
        
    - предотвращения злоупотреблений,
        
    - технического обслуживания сервиса,
        
    - диагностики и исправления ошибок системы.
        

Ожидается, что администраторы используют такой доступ исключительно в случаях, необходимых для работы сервиса.

### 2.2 Частное хранение

Некоторые функции могут позволять пользователям настраивать собственную инфраструктуру хранения в Telegram.

В этом режиме:

- пользовательский контент хранится в инфраструктуре, контролируемой самим пользователем,
    
- Боту может потребоваться административный доступ для выполнения технических операций,
    
- администраторы Бота не осуществляют постоянный контроль или модерацию такого контента, за исключением случаев, связанных с соблюдением законодательства или защитой сервиса.
    

Функция частного хранения может быть доступна только пользователям с премиум-доступом.

## 3. Публичный контент и обмен

Пользователи могут по своему выбору делать часть контента публичной с помощью функций обмена.

Если пользователь делает контент публичным:

- он может быть доступен другим пользователям через специальные ссылки,
    
- могут фиксироваться показатели взаимодействия, такие как просмотры, отметки «нравится» или подписки.
    

Пользователь несет ответственность за контент, который он делает публичным.

- преследования, оскорблений или злоупотреблений,
    
- попыток нарушить работу сервиса или использовать его ненадлежащим образом.
    

Оператор сервиса оставляет за собой право ограничивать доступ, удалять или модерировать контент, нарушающий данные правила или действующее законодательство.

## 5. Собираемые данные

Бот может обрабатывать определенные данные, предоставляемые Telegram при взаимодействии пользователя с сервисом. К таким данным могут относиться:

- идентификатор пользователя Telegram (user_id),
    
- имя пользователя (username),
    
- отображаемое имя,
    
- языковые настройки,
    
- контактные данные, добровольно предоставленные пользователем через Telegram (например номер телефона),
    
- данные взаимодействия, необходимые для функционирования сервиса.
    

Эти данные используются исключительно для обеспечения работы сервиса.
